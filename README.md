# FINDKOM — Sistem Laporan Kehilangan & Penemuan Barang FILKOM UB

Starter project Laravel untuk tugas RSI Kelompok 4 (Modul 1–3).
Stack: Laravel 12 · Blade · MySQL 8.0 (XAMPP) · Apache/`artisan serve`.

## Instalasi (XAMPP)
1. Nyalakan **Apache** & **MySQL** di XAMPP.
2. Buat skeleton Laravel, lalu timpa dengan isi starter ini:
   ```bash
   composer create-project laravel/laravel findkom "^12.0"
   cd findkom
   # salin semua file/folder starter ini ke sini (replace)
   # hapus 3 migration bawaan skeleton:
   #   database/migrations/0001_01_01_000000_create_users_table.php
   #   database/migrations/0001_01_01_000001_create_cache_table.php
   #   database/migrations/0001_01_01_000002_create_jobs_table.php

   ini alya
